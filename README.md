# YouTube Playlist Downloader

A Python script that downloads all videos from a specified YouTube playlist to your local machine. It utilizes the YouTube Data API to fetch playlist details and yt-dlp for downloading the videos in high-quality MP4 format.

## Features

- Fetches and downloads all videos from a specified YouTube playlist.
- Uses the YouTube Data API to retrieve video information.
- Downloads videos in the best available quality (video + audio).
- Supports automatic folder creation for downloads.
